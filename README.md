# Vision-AI-Taskphase

WORD CLOUD
The word cloud project was a simple application of everything we learnt in the course by Google. We used some  pre-defined functions like  isalpha(), split(). 
After splitting, we remove the punctuations and and uninteresting words. Then, create a dictionary of the remaining words to obtain word frequency.
Finally, .WordCloud() function is used to map out the word cloud and obtain an image.
